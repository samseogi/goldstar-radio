2. Capacitor CLI로 네이티브 APK 빌드

npm init @capacitor/app goldstar-radio

cd goldstar-radio && npm install @capacitor/android

npx cap add android

# index.html 파일을 www/ 폴더에 복사

npx cap copy

npx cap open android # Android Studio에서 APK 빌드
